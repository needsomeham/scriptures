MOC — Koine Greek learning

Every sources/ note on learning/reading Koine Greek, grouped by sub-topic. See [[learning-path]] for how these fit into stages, and _control/references-greek.md for the bibliography shard (grep by [G-NN] ID; don't read end-to-end).

Pronunciation

  • pronunciation-erasmian-vs-restored-koine — neutral overview of

Erasmian/restored-Koine/Modern choices (Stage 0).

First-year grammars

  • decker-reading-koine-greek — reading-first, aspect-first spine

(Stage 1 primary).

  • mounce-basics-of-biblical-greek — most widely used seminary

grammar; alt/reference spine.

  • croy-primer-of-biblical-greek — compact single-semester

alternative.

  • funk-beginning-intermediate-grammar — free, linguistically rigorous,

bridges to BDF; free-path spine option.

  • athenaze-attic-caveat — caveat note: popular Attic-Greek primers

are not Koine; scope warning, not a path resource.

Reference/intermediate grammars

  • wallace-greek-grammar-beyond-basics — standard exegetical syntax

reference (Stage 2+).

  • runge-discourse-grammar — discourse-linguistics account of word

order/connectives (Stage 2–3).

Lexicons

  • bdag — field-standard NT lexicon (Stage 2+, paid).
  • abbott-smith-lexicon — free public-domain everyday lexicon.
  • louw-nida-lexicon — semantic-domain lexicon.
  • logeion — free digital lexicon aggregator (incl. LSJ).
  • metzger-lexical-aids — frequency/cognate vocabulary index.

Videos & courses

  • biblicaltraining-mounce-nt201 — free full video course (Mounce).
  • billmounce-site — Mounce's free video/vocab hub.
  • daily-dose-of-greek — daily verse-by-verse reading habit (all

stages).

  • biblical-language-center-living-koine-greek — spoken-immersion,

restored-pronunciation course (paid).

  • ancient-language-institute-koine — live cohort-based course (paid).
  • biblingo — subscription spaced-repetition app (T3, credentials

unverified — see gaps).

Reading tools & readers

  • tyndale-house-greek-nt-readers-edition — glossed reader's edition

(Stage 2).

  • ubs5-readers-edition — sibling glossed reader's edition.
  • step-bible — free interlinear/morphology/lexicon platform.
  • perseus-digital-library — free tagged corpus + parser (wider Greek).
  • biblearc — arcing/bracketing sentence-diagram tool.

Datasets (LXX/NT text, for future tooling)

  • open-greek-nt-datasets — MorphGNT, SBLGNT, OpenGNT, Nestle 1904;

open machine-readable tagged Greek NT text.

Start here / practice

  • start-here — Jacob's concrete Stage 0 on-ramp (day-by-day).
  • progress-log — stage-readiness checklist and reading log.
  • greek-alphabet-and-diacritics — alphabet/diacritics reference

table used throughout Stage 0.

  • 1-john-1-1-4-first-reading — first guided reading, a Stage 0/1

bridge into real NT Greek.
