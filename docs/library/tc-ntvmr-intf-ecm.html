NTVMR (New Testament Virtual Manuscript Room) and the Editio Critica Maior

Source
SourceT1intermediatefreeTextual criticism#manuscripts, #tool, #free, #institution

In one line: Münster's INTF hosts the field's primary online manuscript database and the in-progress Editio Critica Maior (ECM), the most exhaustive critical edition being built book by book.

What it is: The Institute for New Testament Textual Research (INTF, University of Münster) runs the New Testament Virtual Manuscript Room (ntvmr.uni-muenster.de), a free portal aggregating digitized images, transcriptions, and collation data for thousands of NT manuscripts, plus tools implementing tc-cbgm. The ECM is INTF's ongoing critical edition with full apparatus per book; completed volumes include Catholic Epistles (feeding NA28), Acts (2017), Mark (2021), and Revelation (2024), with more books in progress [T-01][T-07].

Use in the path: Once you can read an apparatus entry, use NTVMR to look up an actual manuscript image for a variant you're studying — closes the loop from printed apparatus siglum to physical page. Advanced/technical users can explore the CBGM tool interface directly.

Strengths: Free, primary-source access (not secondary description); directly run by the body that produces NA/UBS/ECM, so it's as authoritative as sourcing gets; strong fit for an engineering mindset (the CBGM tool exposes witness-relationship data).

Weaknesses / cautions: Interface is research-grade, not learner-friendly; transcription coverage is uneven across manuscripts/books; ECM is incomplete — most of the NT still awaits its ECM volume, so NA29's full rollout has no announced date [T-01].

Claims to note: n/a (primary data tool) — but note ECM/NA29 status is still queued/in-progress as of 2026, not settled.
