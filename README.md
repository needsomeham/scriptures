# Scriptures

This is Jacob's working vault for learning New Testament Greek from the
ground up and understanding the New Testament in its original historical
and textual context — an academic, non-sectarian research notebook, not
a devotional or study-Bible app. It's built as an Obsidian vault: plain
markdown notes on Greek grammar, historical background, and textual
criticism, linked together and organized around a concrete Greek-learning
curriculum. It's a living, growing reference meant to be read a little at
a time by lookup, not cover to cover.

**Open `MAP.md` first** — it explains how everything is organized and
where to go next. To begin learning, open start-here.md.
