# Greek Study Site — Build Spec (v1)

Repo = the Scriptures vault (markdown at root). The site lives in two folders:

```
site/            build tooling + templates + hand-written assets (committed)
  build.py       Python 3, stdlib only (+ `markdown` and `pyyaml` allowed — pin in site/requirements.txt)
  templates/     Python string templates or Jinja2-free f-string templates (keep simple)
  static/        style.css, app.js, icons.svg, data/*.json (hand-authored data)
docs/            BUILT OUTPUT — GitHub Pages serves this from `main`. Never hand-edit; `python site/build.py` regenerates it.
```
Run: `python3 site/build.py` from repo root → writes docs/. Must be idempotent and finish in < 5 s. No CI required (Pages: Settings → Pages → Deploy from a branch → main, /docs).

## Design system (binding; from the approved canvas)
Tokens (also in `site/static/style.css` as CSS custom properties):
- bg `#faf6ee` · panel `#fffdf7` · band `#f2ecdf` · rule `#e3d9c8` · rule-strong `#c9b894`
- ink `#2a2419` · ink-muted `#6b6052` · label `#a3937a` · accent `#9c6f2f` · accent-soft `#f5efe1` · highlight `#ecdcb8`
- Fonts (Google Fonts link in every page `<head>`): **Gentium Plus** (Greek, headings, passage text) · **IBM Plex Sans** (UI, body, labels). Fallbacks: Georgia/serif; system-ui/sans-serif. No mono.
- Labels: 11px uppercase, letter-spacing .18em, color label. Body 16px/1.55. Greek passage 24–28px desktop, 22–24px mobile. Panels: panel bg on 1px rule, radius 0, no shadows. Primary button: solid accent, bg text; secondary: accent-soft with rule border. Controls ≥ 40px desktop, ≥ 48px mobile.
- **Desktop (≥ 900px):** left rail 216px (band bg) with wordmark, 5 nav items (Dashboard · Course · Alphabet · Reading Room · Library), active = panel bg + rule-strong border; content area max 1200px; layouts per the canvas (next-action strip with 3px accent left rule, 4-up metric row, two-column panels).
- **Mobile (< 900px):** single column, bottom tab bar (5 tabs, inline SVG stroke icons, ≥ 60px tall, active = accent top rule), masthead at top. No fake status bar.
- Icons: inline SVG, 24-grid, stroke 1.6, currentColor. Copy the exact five nav icons from `/home/claude/greek-site-design/STYLE.md`.
- Light theme only for v1 (paper is the brand). Respect `prefers-reduced-motion`.

## Data contracts (hand-authored JSON in site/static/data/, copied to docs/data/)
- `course.json` — `{stages:[{id:0..3,title,duration,goal,ready_when:[...],resources:[{title,url,note_slug}]}], plan:[{day:1..14,title,minutes,resource_slug?,url?,detail}]}` — content from `start-here.md` + `learning-path.md` (Agent A authors from the vault; verbatim titles).
- `alphabet.json` — 24 letters: `{upper,lower,final?,name,erasmian,koine,confusion?}` from `concepts/greek-alphabet-and-diacritics.md` (Agent B).
- `readings/1jn-1-1-4.json` — `{ref,source:"SBLGNT",license_note,clauses:[{verse,greek,gloss,words:[{surface,lemma,parse,gloss,note?}]}], observations:[{title,claim,body}], tasks:[...]}` — Greek per SBLGNT; per-word lemma+parse from **MorphGNT** (github.com/morphgnt/sblgnt, file `83-1Jn-morphgnt.txt` (MorphGNT numbers 1 John as book 23 → BCV codes 2301xx), CC BY-SA 3.0 — attribute in the page footer); glosses/observations from `bridges/1-john-1-1-4-first-reading.md` (Agent B).
- `library-index.json` — `[{slug,title,type,tier?,level?,cost?,moc,one_line,tags,url}]` + `search.json` (slug → lowercase text) (Agent C, generated by build).

## Progress store (app.js, Agent A) — `localStorage` key `greek-study:v1`
`{stage:0, days:{"1":"2026-09-20",...}, streak:{last:"YYYY-MM-DD",count:n}, minutes:[{date,min,what}], letters:{"ξ":{seen,correct}}, readings:{"1jn-1-1-4":{opened,tasksDone:[...]}}}`
API: `Progress.get()`, `Progress.markDay(n)`, `Progress.touch()` (updates streak once per calendar day), `Progress.logMinutes(min, what)`, `Progress.letterResult(ch, ok)`, `Progress.export()` → JSON download, `Progress.import(json)`, `Progress.reset()`. Dashboard metrics derive from this (streak, days done/14, letters known = ≥3 correct & ≥75%, minutes this week). Empty state must look intentional (no fake numbers) — "Day 1 · start here".

## Interactions
- **Dashboard:** next action = first unchecked plan day; "Start" links to course.html#day-N; passage panel shows 1 John 1:1 with link to reading.html; metrics from Progress.
- **Course:** stage tabs (0 active by default; others viewable), day rows with checkbox → `Progress.markDay`, resource links open in new tab, "Ready when" checklist (stored), stage-advance button.
- **Alphabet:** Learn mode = 6×4 grid, click → focus panel (both pronunciations, confusion note); pronunciation toggle (persist choice); Quiz mode = 10-question rounds (prompt: lowercase glyph → pick name, or name → pick glyph; 4 options; weak letters weighted ×3); results feed `Progress.letterResult`. Keyboard: 1–4 answer.
- **Reading Room:** clause-by-clause layout; tap/click a word → parse card (desktop: side panel; mobile: bottom sheet); "What the Greek adds" as `<details>`; tasks as checkboxes → Progress. Reading list left rail (only 1 John 1:1–4 for now; structure for more).
- **Library:** MOC tree, filter chips (All/Sources/Concepts/Bridges/MOCs), search (client-side over search.json, substring + simple ranking), results list; note pages render markdown with wikilinks → `library/<slug>.html`, frontmatter as a meta strip (type/tier/level/cost/tags), backlinks section, "Open in vault" (GitHub link `https://github.com/needsomeham/scriptures/blob/main/<path>`). Skip `_templates/`, `SPEC.md`, `SITE-SPEC.md`, `site/`, `docs/`; include root notes (MAP, learning-path, start-here, progress-log, README) under type "guide".

## Quality gates (QA agent)
- `python3 site/build.py` clean; docs/ has no absolute `/` links (Pages serves at `/scriptures/` — use **relative** links everywhere, e.g. `../index.html`, `data/course.json` resolved relative to page).
- Playwright screenshots of every page at 1440×900 and 390×844 into `qa/screens/`; no horizontal scroll at 390; Greek renders (Gentium loaded or fallback readable).
- All internal links resolve; all wikilinks in library resolve or render as plain text with a `.missing` class (never a dead link).
- Lighthouse-ish basics: `<title>`, lang="en" with `lang="grc"` on Greek spans, alt on images, focus styles visible.
